Start Tonight

From Justification toward Sanctification · You don’t have to finish the whole book before you obey · NLT

If you already know the gap — you can explain patience and still lose it at home — begin here.

The five steps

  1. Notice — Pause ~3 seconds. Name what is rising. It is in you; it is not the whole of you in Christ.
    Cue: “Something is rising — I see it.”
  2. Discern — Galatians 5: sinful nature or Spirit’s fruit?
    Cue: “Which list does this belong to?”
  3. Declare — Speak one Scripture into the moment.
    Anger: Eph 4:26 · Anxiety: Phil 4:6 · Envy: 1 Cor 13:4 · Bitterness: Eph 4:31–32
  4. Return — Brief prayer. Peace follows; it need not come first.
    Cue: “Lord, rule here. Help me love them.”
  5. Act — Do the next faithful thing now.
    Soften. Apologize. Wait one minute. Send the honest text.

Home scripts (steal these)

Bedtime / sharp tone: Notice heat → “This is anger, not wisdom” → Eph 4:26 → “Lord, rule my mouth” → one softer sentence.

Morning rush: Notice urgency-as-control → “Fruit is patience” → breathe once → “Help me love them” → give thirty more seconds before the lecture.

3 a.m. worry: Notice the rehearsal → “This is anxiety manufacturing evidence” → Phil 4:6 → thank God for one thing → write two action items, leave the rest for morning.

Phone in bed / night scroll: Notice the hand reaching → “This is not rest; this is anesthesia” → Phil 4:6 → “Lord, rule here; I will not scroll my way out” → lock screen, write two things if needed, lights out. Sleep first; calm can follow.

Seven days

  1. Pick one trigger.
  2. Run the five steps every time it appears (clumsy counts).
  3. Tell one person in one sentence; ask them to check Sunday.
  4. Evening: three lines only — what rose (and when), what I did, one thing for tomorrow.

Not emptying yourself of feeling. Yes refusing to let feeling drive while love waits.

Justified once. Sanctified daily.
